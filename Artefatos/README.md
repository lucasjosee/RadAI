# Artefatos

Esta pasta destina-se aos artefatos de gestão do projeto (atas de reunião, Business Model Canvas, backlog, histórias de usuário).

Os artefatos produzidos durante o desenvolvimento foram mantidos localmente por conterem informações acadêmicas internas da disciplina. As apresentações por Sprint estão disponíveis em [`Divulgacao/Apresentacao/`](../Divulgacao/Apresentacao/).
